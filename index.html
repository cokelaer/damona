--- layout: default title: Damona registry description: Searchable registry of Singularity containers for bioinformatics ---

Damona is a conda-style package and environment manager built on Apptainer/Singularity containers. Install bioinformatics tools as isolated containers, keep several versions side by side, and run them like any command-line tool, with no root privileges.

pip install damona
damona create myenv
damona activate myenv
damona install fastqc:0.11.9
